# Win10系统安装教程

> 进入BIOS调整开机顺序

> **** 非常重要！！！说三遍！！！****

> 开电脑之后，出现主板logo，狂按几次DEL或者F12键盘（不同电脑不一样，屏幕有显示，没有的话看主板说明书，台式机大部分都是小键盘DEL，笔记本有的是F2，有的是F12）

![](images/wp-content_uploads_2022_11_image-29.png)

电脑会读取 U盘进行启动，界面如下：我们直接点下一步

![](images/wp-content_uploads_2022_11_image-30.png)

直接点击：直接安装

![](images/wp-content_uploads_2022_11_image-31.png)

勾选许可 下一步

![](images/wp-content_uploads_2022_11_image-32.png)

> 重点！！！重点！！！重点！！！

选择自定义：仅安装Windows (高级)（C）

![](images/wp-content_uploads_2022_11_image-33.png)

如果只有一个新硬盘 直接下一步
如果是重装请找到系统硬盘 比如我这个驱动器0 下的分区全全删除了 然后选驱动器0 再点一下 下一步

![](images/wp-content_uploads_2022_11_image-34.png)

我们等待读取数据… 然后自动重启

![](images/wp-content_uploads_2022_11_image-35.png)

自动重启后会出现 设置Windwos 现在开始设置windwos

![](images/wp-content_uploads_2022_11_image-36.png)

输入法 随便点一个 反正都要删除的- -

![](images/wp-content_uploads_2022_11_image-37.png)

我们直接跳过 键盘布局

![](images/wp-content_uploads_2022_11_image-38.png)

看清左下角 点一下 改为域加入

![](images/wp-content_uploads_2022_11_image-39.png)

到这个之后 傻瓜式一直点 是 确定 接受

![](images/wp-content_uploads_2022_11_image-40.png)

![](images/wp-content_uploads_2022_11_image-41.png)

![](images/wp-content_uploads_2022_11_image-42.png)
