# Win10如何关闭Defende

首先点一下"开始" ”设置"

![](images/wp-content_uploads_2022_11_image-51.png)

找到 “更新和安全”

![](images/wp-content_uploads_2022_11_image-52.png)

左边找到“Windows安全中心” 右边 “病毒和威胁防护“

![](images/wp-content_uploads_2022_11_image-53.png)

找到 “管理设置”

![](images/wp-content_uploads_2022_11_image-54.png)

找到这三个 全部关闭 然后退回 桌面

![](images/wp-content_uploads_2022_11_image-55.png)

打开“运行”工具，输入“gpedit.msc”，点击“确定”

![](images/wp-content_uploads_2022_11_image-56.png)

“计算机配置”下“管理模板” -"Windows组件“-Windows Defender防病毒程序

![](images/wp-content_uploads_2022_11_image-57.png)

双击“关闭Windows Defender防病毒程财塑序”选项，弹出窗口中勾选“已启用”选项，点击“确定”。

![](images/wp-content_uploads_2022_11_image-58.png)

![](images/wp-content_uploads_2022_11_image-59.png)

关闭所以窗口 重启一下 到此 就可以关闭 Windows Defender.
