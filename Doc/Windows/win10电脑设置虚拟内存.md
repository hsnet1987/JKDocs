# Win10电脑设置虚拟内存

鼠标右击“此电脑”，点击“属性"

![](images/wp-content_uploads_2022_11_image-50.png)

在系统窗口中，选择“高级系统设置

![](images/wp-content_uploads_2022_11_image-44-1024x622.png)

在高级选项卡，点击性能下面的“设置”

![](images/wp-content_uploads_2022_11_image-45.png)

点击“高级”菜单，找到“虚拟内存”，点击“更改”

![](images/wp-content_uploads_2022_11_image-46.png)

把自动管理所有驱动器的分页文小 取消

![](images/wp-content_uploads_2022_11_image-47.png)

把C盘设置 无分页文件 点下 设置

![](images/wp-content_uploads_2022_11_image-48.png)

在D盘 设置自定义大小 最小值 1000 最大值 最好是实际内存的1.5倍 比如32G内存 最大值 48000

![](images/wp-content_uploads_2022_11_image-49.png)

然后确定 提示重启 下系统 就好了.
